AI Interior Design Generator

An AI-powered web application that generates interior design images based on user text prompts.

Features:
- Text-to-image interior design generation
- Multiple interior styles
- Google Colab GPU support
- Gradio-based web UI

Tech Stack:
Python, PyTorch, Stable Diffusion, Hugging Face, Gradio

How to Run:
1. Open notebook in Google Colab
2. Enable GPU runtime
3. Run all cells
4. Enter a text prompt
5. Generate and download images

Sample Prompts:
- Modern living room with wooden flooring
- Minimalist bedroom with warm lighting
